### 【封印物-非凡物质聚合异变词条出现概率】

| **词条类型**          | **概率（含保底）** | **保底次数** |
| --------------------- | ------------------ | ------------ |
| 稀有词条（以3+3为例） | 1.95%              | 73           |
| 愚者（以4+4为例）     | 1.12%              | 105          |

备注：在满足异变条件的其他合成情况下，保底值增加将会根据实际消耗调整

##### 有人问客服说5+3, 6+2也会积累保底, 但是占比比较低, 原话是: "4+4是105次保底, 5+36+2次数会多, 暂没有具体次数给到"
