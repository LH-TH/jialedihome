###  鹅阵营 (Goose)
鹅阵营的主要目标是完成任务或找出并投票淘汰所有鸭子。（好人阵营）

| 角色名称   | 技能名称     | 技能描述                                                     |
| :--------- | :----------- | :----------------------------------------------------------- |
| 大白鹅     | 报告         | 你可以报告尸体，之后将进入会议。                             |
| 加拿大鹅   | 报告         | 你可以报告尸体。被动：当你被击倒或被吞噬时会自动发起报告。   |
| 正义使者   | 击倒         | 你可以击倒一名玩家，该技能整局只能使用一次。                 |
| 警长       | 击倒         | 你可以击倒其他玩家，但如果该玩家是鹅，你将一起出局。         |
| 跟踪者     | 观察         | 使用技能后视野变为扇形且可以穿透墙壁，箭头会指示目标所在的位置。 |
| 观鸟者     | 观察         | 使用技能后视野变为扇形且可以穿透墙壁（注：根据角色介绍，主要是收集小地图中其他玩家位置及破坏者大致位置）。 |
| 工程师     | 地道         | 你可以进入地道进行快速移动或躲藏在背身处。                   |
| 通灵者     | 灵魂出窍     | 使用技能后可以穿越墙壁观察其他玩家，但你的本体会留在原地无法移动。 |
| 星界行者   | 灵魂出窍     | 使用技能后可以穿越墙壁观察其他玩家，但你的本体会留在原地无法移动。 |
| 模仿者     | 调查         | 使用调查，了解目标玩家在本回合是否使用了击倒技能。           |
| 侦探       | 调查         | 使用调查，了解目标玩家在本回合是否使用了击倒技能。           |
| 清醒梦者   | 出梦         | 离开地图返回会议中。                                         |
| 替罪者     | 替罪         | 被投出局时，可以带走1位给你投票的玩家。                      |
| 冒险家     | (无主动技能) | 环境破坏无法击倒你。                                         |
| 说客       | 击倒         | 每被投一定票数后，你都可以击倒一次。                         |
| 生存主义者 | 隐藏         | 触发生存倒计时后一段时间解锁，使用后可以短暂隐形，移动会自动显形。 |
| 复仇者     | 击倒         | 目睹一场击杀后，在规定时间内你可以击倒一名玩家。             |
| 探测员     | 扫描         | 使用技能后可以在小地图上短暂的显示所有存活玩家的位置。       |
| 士兵       | 击倒         | 每完成一定数量的任务后，你都可以击倒1次。                    |
| 法医       | 报告         | 报告鸡腿时，你将在会议中获得一次额外的投票权。               |
| 殡仪员     | 查验         | 查验成功后，下次会议上你能看见被查验的尸体的真实身份。       |
| 恶魔猎手   | 击倒         | 当腐化值到达100%后，可以击倒一名玩家（腐化模式限定）。       |
| 肉汁       | (无主动技能) | 通过完成任务来增加赏金，生存到最后才能得到该赏金。凶手只能在和你单独相处的时候淘汰你。 |
| 网红       | (无主动技能) | 所有的鹅在你出局时会收到报警提示。                           |

### 鸭子阵营 (Duck)
鸭子阵营的主要目标是击倒所有鹅或完成破坏任务。（坏人阵营）

| 角色名称 | 技能名称           | 技能描述                                                     |
| :------- | :----------------- | :----------------------------------------------------------- |
| 鸭子     | 击倒 / 破坏        | 你可以击倒一名玩家；可以使用破坏技能对门和紧急设备进行破坏。 |
| 专业杀手 | 击倒 / 破坏        | 你可以击倒一名玩家，鹅无法看到被你击倒的玩家（无法主动报告尸体）。 |
| 爆炸王   | 炸弹 / 破坏        | 放置炸弹，15秒后爆炸，对范围内的玩家造成伤害（可传递）。     |
| 刺客     | 刺杀 / 破坏        | 可以在会议上使用技能刺杀别人（猜对身份对方出局，猜错自己出局）。 |
| 变形者   | 吸取 / 变形 / 击倒 | 靠近一名玩家吸取样子；使用技能变成TA的样子。                 |
| 隐形鸭   | 隐形 / 击倒        | 使用技能后进入隐身状态，对所有人隐形，增加50%移动速度。      |
| 牧师     | 加票 / 击倒        | 可以选择一名非鸭子玩家增加其投票权重。                       |
| 杀手     | 击倒 / 破坏        | 击倒减少自己冷却时间，其他玩家击倒增加冷却时间。             |
| 身份窃贼 | 击倒 / 破坏        | 在召集会议之前，你会自动变形为你最近击倒的玩家。             |
| 间谍     | 击倒 / 破坏        | 会议投票时，你可以投票给一名玩家，当你是唯一投票的人，下次会议时你将得知TA的身份。 |
| 食鸟鸭   | 吞食 / 击倒        | 使用技能后可以吞食一个鸡腿（每局一次）。                     |
| 狙击手   | 瞄准 / 开枪        | 站在原地远程瞄准其他玩家；将击倒瞄准范围内的所有玩家。       |
| 投毒者   | 投毒               | 对其他玩家下毒，用延时发作的毒药进行击倒。                   |
| 忍者     | 击倒 / 畅行禁区    | 可以同时击倒范围内的两名玩家（冷却时间长）；可以在禁区内行走。 |
| 默剧演员 | 附身 / 操控        | 选择一名玩家附身；成功附身后点击操控随机将自身行为同步到对方身上。 |
| 静语者   | 沉默 / 击倒        | 被沉默的玩家无法在会议中说话。                               |
| 异形     | 变身 / 击倒        | 变身为异形，此时其他玩家无法辨认出你是谁。                   |
| 食罪者   | 自爆 / 破坏        | 腐化值达到100%可以启动炸弹，淘汰周围3名玩家，否则自己出局（腐化模式限定）。 |
| 超能力者 | 超能力 / 破坏      | 使用技能后，你可以附身一名玩家和TA远程交流（被附身玩家会议阶段发言有变声）。 |
| 小丑     | 塞气球 / 击倒      | 给玩家塞气球，收到气球的玩家在会议外被塞两个气球的玩家会在投票阶段爆炸。 |
| 掠夺者   | 搬运 / 窥视 / 击倒 | 拿起鸡腿移动（减少嫌疑）；获得穿透墙壁的视力。               |
| 巫医     | 搬运 / 窥视 / 击倒 | 使用技能将获得穿透墙壁的视力，视野会随行走方向变化，再次使用取消窥视 |

### 中立阵营 (Neutral)
中立阵营有各自独特的胜利条件。

| 角色名称   | 技能名称    | 技能描述                                                     |
| :--------- | :---------- | :----------------------------------------------------------- |
| 鹈鹕       | 吞噬        | 使用技能后可以吞噬附近的一名玩家（被吞玩家在肚子里可交流）。 |
| 呆呆鸟     | 报告        | 想方设法制造自己的嫌疑，当你被投票出局，就能获得胜利。       |
| 鸽子       | 感染        | 使用技能感染附近的一名玩家，被感染的玩家名字旁将出现一个感染标识（感染所有存活玩家获胜）。 |
| 秃         | 吞食        | 使用技能后可以吞食一个鸡腿（吃掉足够的鸡腿获胜）。           |
| 猎鹰       | 击倒        | 你可以击倒一名玩家（尽量隐蔽，剩余3人时进入猎鹰时间，活到最后获胜）。 |
| 布谷鸟     | 孵化        | 每局游戏一共可以孵化3个蛋，孵化出小布谷鸟（其他玩家可站在蛋旁边打碎蛋）。 |
| 乌鸦       | 腐化        | 短暂延迟后，使一名玩家的腐化值提升（所有玩家腐化值≥50%进入乌鸦时刻，乌鸦获得范围击杀刀）。 |
| 喜鹊       | 入梦 / 击倒 | 可在会议阶段以黑魂模式离开会议；如果在会议上猜对其他玩家的角色，可以击倒TA（猜错自己出局）。 |
| 渡鸦       | 击倒 / 报告 | 完成所有任务获得击倒其他渡鸦的能力；在另一只渡鸦被淘汰后，自己被投票淘汰后获胜。 |
| 决斗呆呆鸟 | 击倒 / 报告 | 完成指定数量的任务后，可以击倒另外一只决斗呆呆鸟；在另一只被淘汰后，自己被投票淘汰后获胜。 |
| 锦鸡       | 红包        | 向一名玩家发放红包，TA将获得一个随机红包技能（发放一定数量红包后获胜）。 |
